# 桃屁屁（Peach Butt）桌面宠物

一只「又是桃子、又像屁股、还是个气球」的桌面宠物。住在屏幕边缘，提醒你防久坐、喝水、上厕所，陪你番茄专注。核心机制：**你越不休息、越不点它，它就越鼓，最后「砰」地爆炸、扣血、成长变差；照顾自己就能帮它泄压长大。** 面向 macOS + Windows，目标 Steam 上架售卖。

## 关键结论速览

1. **生图 API 已打通**：文生图 + 图生图均实测通过（详见 docs/05）。
2. **素材可以纯视频、不用建模**：桌面宠物是 2D 帧动画，视频抽帧 + 抠图即可；每个交互动作 = 一段透明循环动画。
3. **不要用 GIF**：用 PNG 序列/精灵表，或 APNG/WebP（真彩 + 半透明，体积更小）。
4. **参考图当前没有透明通道**（RGB），需要抠背景。
5. **跨平台建议首版统一**（Electron 或 Tauri），不首版就拆双原生。
6. **核心机制 = 压力→肿胀→爆炸→扣血→成长**：不休息就鼓、爆了就扣血、照顾就长大（PRD 第 6 章）。
