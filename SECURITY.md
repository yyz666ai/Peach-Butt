# Security Policy

Please do not open a public issue for a vulnerability that could expose local activity data or execute untrusted code. Use GitHub's private vulnerability reporting for this repository when available.

Include the affected version, platform, reproduction steps, and impact. Never attach a real user database, access token, or other private data.

Security fixes are prioritized for the latest `main` branch. This early-stage project does not yet promise a fixed support window for older builds.
