# Local source-video masters

Place authorized source MP4 or MOV clips here when rebuilding transparent motion assets. Source masters are excluded from the public repository because they can contain creation-platform identifiers and private production metadata.

The application uses the checked-in files under `assets/video/generated/`. See [`../../../docs/video-asset-workflow.md`](../../../docs/video-asset-workflow.md) for the processing and validation workflow.
