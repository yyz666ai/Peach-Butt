# 桃屁屁（Peach Butt）桌面宠物 · 产品需求文档（PRD）

> 版本：v0.3（草案）
> 目标平台：macOS + Windows（Steam 可上架售卖）
> 产品形态：常驻桌面的透明置顶小宠物 + 健康提醒 + 番茄计时 + 压力/肿胀/爆炸养成 + 血量统计看板

---

## 1. 产品一句话定位

**桃屁屁是一只「又是桃子、又像屁股、还是个气球」的桌面宠物，住在你的屏幕边缘。它的核心机制是：你越不休息、越不点它，它就越「憋」——压力值一路涨、身体越来越鼓，最后「砰」地爆炸、扣掉血量，成长就会变差；而你只要照顾自己（喝水/起身/上厕所/番茄休息）或摸摸它，就能帮它泄压，让它健康长大。**

核心价值：程序员/久坐办公人群离屏幕最近，把「休息提醒」变成一个**看得见、会爆炸、要负责**的养成游戏，提醒到达率最高、最有情绪钩子、最愿意持续互动。

---

## 2. 背景与要解决的问题

| 问题 | 现状痛点 | 桃屁屁的解法 |
|---|---|---|
| 久坐 | 一坐 2 小时不动，腰颈告警 | 定时提醒起身/拉伸；**不休息压力值会涨到爆炸** |
| 少喝水 | 忙起来完全忘记喝水 | 桌面宠物端水/口渴动画 + 打卡 + 泄压 |
| 憋尿 | 专注起来不去厕所 | 柔和「上厕所」提醒，不打断心流 |
| 番茄专注 | 番茄钟 app 太「工具化」 | 宠物陪跑：专注时安静陪伴，休息时泄压 |
| 坚持难 | 提醒 app 装完就忘 | 游戏化养成：**不照顾它会爆炸扣血，照顾它会长大升级** |

## 3. 目标用户与使用场景

### 3.1 用户画像
- **核心用户**：程序员、设计师、剪辑师、远程办公者 —— 每天 8~12 小时盯屏幕。
- **次核心用户**：学生、游戏玩家、桌面美化爱好者、喜欢「电子宠物」的泛人群。

### 3.2 典型场景
1. 上班开机 → 桃屁屁出现在屏幕右下角，开始待机呼吸动画，压力值 0，血量 100。
2. 进入工作/番茄 → 压力值随时间缓慢上升，桃屁屁从「正常」慢慢「微鼓」。
3. 你一直不休息、不点它 → 它越来越鼓，开始颤抖、脸红、弹预警「我要爆啦！起来动一动吧」。
4. 你还是没管它 → **「砰」爆炸**，压力归零、**血量 -25**，桃屁屁瘪掉泄气，需要「吹气恢复」。
5. 你及时起身/喝水/上厕所/摸摸它 → 压力下降，桃屁屁泄压，开心蹦跳，血量回血，+XP。
6. 番茄结束 → 桃屁屁欢呼 + 弹提示「起来伸个懒腰，去接杯水」，休息泄压。
7. 下班前 → 打开数据看板：今天专注 5 个番茄、坐了 6 小时、喝了 4 杯水、**爆炸 1 次、当日剩余血量 75、近 7 天血量趋势图**。

## 6. 核心玩法机制：压力 · 肿胀 · 爆炸 · 血量（最重要）

> 这是桃屁屁的**灵魂机制**：把「该休息了」变成一个**有后果、要负责、看得见**的循环。

### 6.1 核心循环（一句话）
```
持续工作/不休息/不点它 → 压力值↑ → 身体越来越鼓(5档肿胀) → 压力满「爆炸」→ 血量↓、成长变差
照顾自己/摸摸它 → 压力值↓(泄压) → 桃屁屁开心、血量回血、成长变好
```

### 6.2 压力值 Pressure（0–100）

| 方向 | 触发 | 幅度（初版，可配置） |
|---|---|---|
| ⬆ 上升 | 处于工作/专注状态，随时间匀速上升 | 100 分钟从 0 涨满（≈ +1/分钟，可调） |
| ⬆ 上升 | 番茄「专注中」 | 上升速度 ×1.3（久坐更明显） |
| ⬆ 上升 | **忽视一次提醒**（延后/忽略） | +10（加速爆炸） |
| ⬆ 上升 | 持续全屏工作且无休息（可选，需检测） | +1.5/分钟 |
| ⬇ 下降（泄压） | 点击/抚摸一下 | -5（冷却 30s，防刷） |
| ⬇ 下降（泄压） | 完成喝水/起身/上厕所打卡 | -20 |
| ⬇ 下降（泄压） | 番茄休息完成 | -15 |
| ⬇ 下降（泄压） | 离开电脑空闲一段时间（可选） | 缓慢下降 |

### 6.3 肿胀阶段（视觉 5 档）

| 压力 | 阶段 | 视觉表现 | 提示 |
|---|---|---|---|
| 0–25 | 正常 | 呼吸漂浮，正常大小 | 无 |
| 25–50 | 微鼓 | 轻微膨胀，偶尔皱眉 | 无（或极轻） |
| 50–75 | 鼓胀 | 明显变大，身体紧绷 | 气泡「我好像…有点涨」 |
| 75–99 | 濒临爆炸 | 胀到最大、颤抖、脸红、预警闪烁 | 气泡「我要爆啦！快点点我 / 起来休息！」 |
| **100** | **爆炸 💥** | **爆炸动效（已有素材）** | **扣血** |

### 6.4 爆炸（软失败，不是 Game Over）

- 压力达到 100 → 播放**爆炸动效**（你已制作）→ 压力归 0。
- 爆炸扣血**连爆递增**（越连爆越狠）：

| 当日爆炸次数 | 单次扣血 |
|---|---|
| 第 1 次 | -15 |
| 第 2 次 | -30 |
| 第 3 次及以上 | -50 |

- 血量最低扣到 0，**不死亡**。
- 桃屁屁进入**「瘪掉/泄气」状态**：蔫蔫地瘫着，需要「吹气恢复」才能重新鼓起来。
- 「吹气恢复」：连续点击几次 / 完成任意一次健康打卡（喝水/起身/上厕所）。
- **连爆计数**：当日累计；完成任意一次健康打卡可将连爆**降一档**、次日自动清零（给补救机会，避免一爆到底）。
- 当日爆炸次数 +1，计入统计；连爆有专门惩罚提示（成长受损加重）。

### 6.5 血量 HP（当日活力 + 长期成长）

| 项 | 规则 |
|---|---|
| 每日初始 | 100 |
| 扣血 | 爆炸扣血**连爆递增**：第 1 次 -15、第 2 次 -30、第 3 次起 -50；长时间瘪掉不恢复则成长停滞 |
| 回血 | 完成健康打卡 +5；番茄休息完成 +5（有每日上限，防刷） |
| 死亡 | 血量到 0 不死亡，而是「瘪掉」状态，成长停滞，鼓励补救 |
| **每日结算** | 记录当日血量（结束值 + 最低值 + 平均值），生成「每日血量」图表 |

### 6.6 成长值 Growth（长期，血量驱动）

- 每日结算时：**当日血量越高，成长 +越多；爆炸次数越多，成长受损越大**（甚至负增长）。
- 成长值决定：等级、解锁新动画/表情/皮肤、桃屁屁的「圆润度」。
- 目标：让用户把「今天没爆炸 / 血量高」当成每日成就。

### 6.7 平衡设计（防刷 + 防负面）

- 泄压有**冷却（点击 30s）**和**每日上限**，防止狂点刷满。
- 爆炸是**软失败**：扣血但不死，鼓励补救，不制造挫败感。
- 压力上升速率 / 爆炸扣血（连爆递增：-15/-30/-50）/ 泄压幅度 / 回血上限，全部**可配置**。
- 「专注中压力上升」是刻意的：它代表「你在久坐工作」，休息/起身就是泄压，形成健康闭环。

## 7. 游戏化与数值体系

桃屁屁定位「半宠物、半小游戏」：靠**「爆炸的负反馈 + 成长的成就感」双轮**驱动，不是纯正向。

### 7.1 数值体系（初版建议，可调）
| 指标 | 规则 |
|---|---|
| 压力值 | 见 6.2，核心驱动 |
| 血量 HP | 见 6.5，每日结算 |
| 成长值 | 见 6.6，血量驱动长期成长 |
| XP | 喝水 +5、起身 +10、上厕所 +5、完成番茄 +20、当日无爆炸 +30 |
| 等级 | 成长值/XP 累计，每级解锁 1 个新动作/表情/装扮 |
| 连击(Streak) | 连续「无爆炸日」的天数；爆炸会断连击（可回血） |
| 成就 | 如「连续 7 天不爆炸」「第一次从爆炸中救回来」「桃屁屁等级 10」 |
| 金币/代币(可选) | 用于买皮肤，Steam 成就不绑定付费 |

### 7.2 奖励反馈
- 泄压/打卡成功 → 桃屁屁蹦跳 + 撒花/冒爱心粒子 + 音效（可关）。
- 无爆炸日 → 睡前「今日健康结算」弹窗 + 成长动画。
- 爆炸 → 瘪掉 + 「救我」气泡，引导补救，避免纯挫败。

## 9. 提醒机制设计

### 9.1 默认节奏（首次启动建议值）
| 类型 | 默认间隔 | 默认窗口 |
|---|---|---|
| 喝水 | 60 分钟 | 9:00–22:00 |
| 起身/久坐 | 50 分钟 | 9:00–22:00 |
| 上厕所 | 150 分钟 | 9:00–22:00 |

### 9.2 提醒规则
- **柔和提醒**：先让桃屁屁做「欲提醒」前摇（举杯/扭动），3s 后再弹气泡，避免吓人。
- **勿扰联动**：番茄「专注中」时，只保留到点的番茄提醒，其他提醒延后。
- **一键延后**：气泡上「5 分钟后再提醒 / 已完成」。
- **忽视 = 加压**：每次提醒被延后/忽略，压力 +10（呼应核心机制）。
- **智能让步**：检测到全屏（视频/会议/游戏）时降低提醒频次或改用菜单栏角标。
- **久坐连击预警**：连续 2 个起身提醒未响应 → 桃屁屁变「忧心脸」+ 弹一次更强的提醒 + 压力加速。

### 9.3 所有提醒可完全自定义
间隔、窗口时段、静音、气泡文案、是否显示动画、压力系数。

## 10. 数据统计看板

### 10.1 指标
- **今日血量**：当前血量 / 当日最低血量 / 今日爆炸次数。
- **血量趋势图**：近 7 天 / 30 天每日血量折线图（重点）。
- **爆炸统计**：每日爆炸次数柱状图 + 平均爆炸时间。
- **习惯统计**：专注番茄数 / 专注总时长 / 坐姿时长 / 喝水次数 / 上厕所次数 / 起身次数。
- **压力洞察**：每日压力峰值、泄压次数、被忽视提醒次数。
- **关联分析**：爆炸日 vs 久坐时长/忽视提醒数（提示「哪天你爆了，是因为坐了 X 小时、忽略了 N 次提醒」）。
- **成就墙**：已解锁/未解锁。
- **连击**：当前「无爆炸」连击、历史最长。

### 10.2 呈现形式
- 本地 Web 看板（应用内窗口 / 默认浏览器 `localhost:端口`），图表用轻量前端库。
- **首页第一屏 = 今日血量大数字 + 7 天血量折线图 + 爆炸柱状图**（核心指标优先）。
- 数据**本地优先**，不上传（隐私卖点），Steam 云存档可选。

### 10.3 隐私
- 只记录「行为事件 + 时间戳」，不采集屏幕内容、不录屏、不联网（除 Steam 与更新）。
- 首次启动明示隐私说明。

## 11. 平台与分发

- **平台**：macOS 12+（Apple Silicon / Intel）、Windows 10/11（x64）。
- **形态**：单次购买买断制小游戏，Steam 上架；后续可做内购皮肤（可选，谨慎）。
- **定价建议**：¥6~¥18 低门槛买断，靠「可爱 + 实用」走量；或免费 + 皮肤内购。
- **本地化**：简体中文首发，英/繁/日/韩后续。
- **Steam 特性**：成就、统计、云存档、Overlay、手柄（可选，不必须）。
