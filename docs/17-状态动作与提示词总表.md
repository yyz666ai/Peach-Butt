## 0. 数据流（先看这个，后面所有表都是它的展开）

```
时间/健康引擎 tick
   └─> currentVisual()  （runtime.ts:569，11 级优先级）
         └─> visual id  （如 'pressure' / 'focus:1' / 'deflated'）
               └─> PetMotion clips[visual]  （27 个 key → 24 个 webm）
                     └─> clipTimelines[id]  （start / end / playMode / rate / scale）
                           └─> 运行时叠加：scale 膨胀 · CSS 干裂滤镜 · 0.55x scrub 小窗循环
```

三类播放模式：
- `loop` —— 常驻状态，播完自动回 `start`（idle / focus / sleep / activity / deflated）
- `once` —— 一次性动作，播完停在最后一帧（greeting / pet / shy / dance / happy / kiss…）
- `scrub` —— 按压力值（55→100）映射到 0→5.3s 位置，前后 ±0.45s 小窗循环（只有 pressure）

## 2. 状态机判定顺序（`currentVisual()`，从高到低）

只要命中就立刻返回，不会再往下走：

1. **爆炸中** `visualOverride.id === 'exploding'` → `explosion`
2. **瘪掉** `health.mode === 'deflated'` → `deflated`（分「未开始休息」/「休息中」两种文案）
3. **长休息** `phase === 'break' && breakKind === 'long'` 且未全完成 → `sleep`
4. **休息队列当前项** `restSession.current` → `water-prompt` / `activity` / `toilet` / `eye-strain`
5. **休息四项全完成** → `sleep`（长休）或 `rest`（短休）
6. **番茄结束待确认** `awaiting_rest_confirmation` → `stretch`
7. **提醒命中**：
   - `water` 且忽略 ≥ 15 分钟 → `dry`
   - `eyes` 且忽略 ≥ 10 分钟 → `eye-strain`
   - 其他 → `water-prompt` / `stretch` / `toilet` / `eye-rest`
8. **变身 override** → `transform`
9. `selectPetVisual()`：压力 ≥ 55 → `pressure`；专注中 → `focus`；打招呼 → `greeting`
10. **深夜 23:00–6:00**：5 分钟内有交互 → `eye-strain`（揉眼劝睡）；否则 → `sleep`（打瞌睡）
11. **兜底** → `idle`

另有 5 种**大屏接管**（模态、需点按钮，不是桌宠本体的 visual）：
`water` / `stand` / `toilet` / `eyes`（提醒忽略 ≥ 5 分钟触发）、`anti-sedentary`（连续专注达上限一半 + 15 分钟，swell 档 3 触发）。

## 3. 提示词工程（所有素材生成都走这套）

### 3.1 三段式结构

```
[动作句：首帧中的粉嫩蜜桃小屁屁角色……]  +  FACE_LOCK  +  KEEP  +  [首尾衔接句]
```

### 3.2 两个公共常量（脚本里已定义，直接复用）

```python
FACE_LOCK = (
    "全程保持脸和两只小眼睛正面对着镜头、直视观众，"
    "绝不侧身、绝不转身、绝不背对镜头、绝不 3/4 侧脸、眼睛绝不斜视看向别处。"
)
KEEP = (
    "角色的造型、体型比例、颜色、渐变、打光与首帧完全一致，"
    "背景保持首帧的亮白无阴影，固定镜头，全身完整居中入画。"
)
```

### 3.3 生成 / 抠图 / 接入命令

```bash
# 1) 生成（首帧参考图 assets/reference/peach-front.png，5s 768P，约 2~3 分钟/条）
.venv-video/bin/python scripts/generate-minimax-clip.py \
  --image assets/reference/peach-front.png \
  --prompt "（提示词）" \
  --out assets/video/source/xxx-v8.mp4

# 2) 批量（已封装的脚本）
.venv-video/bin/python scripts/gen-v7.py --all            # 8 条互动素材
.venv-video/bin/python scripts/gen-v7-rewards.py --all    # 3 条奖励素材

# 3) 抠图（v7 管线，阈值 232；新名字要先加进 key-v7.py 的 V7_NAMES + V7_TRIM）
.venv-video/bin/python scripts/key-v7.py assets/video/source assets/video/generated --names xxx-v8

# 4) 校验 + 测试
npm run videos:check && npm test
```

> **接入 checklist**：`manifest.json` 加 clip（含 `fps: 24`）→ `pet-motion-timeline.ts` 加 timeline →
> `PetMotion.tsx` 注册 key → `ffprobe` 确认**文件时长 > end**（否则 loop 会断）→ `videos:check` + `npm test`。

## 5. 需要新写的提示词（13 条）

## 6. 建议新增的动作（当前是缺口）

| 动作 ID | 说明 | 为什么需要 |
|---|---|---|
| **`reinflate`（鼓回来）** | 从瘪掉状态一点一点重新鼓回圆润，最后舒一口气、开心地笑 | **当前最大缺口**：现在 deflated 恢复完全靠 `scale` 线性插值 + CSS，只是「变大」，没有「鼓回来」的质感。有了这条，5 分钟休息结束那一下会有真正的仪式感 |
| `sad`（低落） | 连续忽略提醒时垂头丧气 | 现在只有干裂/变红两条负面线，缺一条纯情绪的 |

| `fart`（放屁桃心泡泡） | 连戳 5 次 | 病毒传播点，`docs/04` 里标过 P2 |
