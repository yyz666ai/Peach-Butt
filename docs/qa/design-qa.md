## 检查结果

| 范围 | 结果 | 证据 |
| --- | --- | --- |
| 视觉层级 | 通过 | 品牌、能量数值、三项摘要、7 天趋势、四项行为形成从上到下的稳定阅读顺序；角色不遮挡图表。 |
| 字体与字号 | 通过 | 能量数字、区块标题、指标、日期、行为标签层级清楚；`0` 分及三项摘要没有与进度条或背景资产重叠。 |
| 间距与对齐 | 通过 | `1050 × 760` 和最小 `960 × 650` 均保持网格对齐；图表、日期、节点和底部标签没有出框。 |
| 响应式 | 通过 | 窗口缩至最小尺寸时进度条与折线随容器宽度重算，四项行为保持四等分，不产生横向滚动。 |
| 色彩与材质 | 通过 | 桃色主体与珊瑚线比背景更醒目；叶绿用于正向状态；奶油承载层保持柔和，不出现灰暗主角。 |
| 图像质量 | 通过 | 房间、角色、拉伸人物、水瓶、眼罩、马桶和桃子节点均使用独立位图资产；没有以 CSS/SVG 临摹角色或 3D 道具。 |
| 文案 | 通过 | 前台只保留必要统计文案；动态每日一句已移除，避免内容长度破坏排版。 |
| 交互 | 通过 | 设置按钮打开固定可滚动设置层，Esc、关闭按钮和遮罩可退出；专注、短休、长休、长休周期与提醒间隔可设置。 |
| 可访问性 | 通过 | 能量使用真实 `progressbar` 语义，`aria-valuenow` 保持 0–100 合法范围，真实分数由 `aria-valuetext` 说明；主要图标按钮有可读标签。 |
