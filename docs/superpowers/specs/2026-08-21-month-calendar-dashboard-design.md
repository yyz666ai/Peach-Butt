# 桃桃小屋月历统计改版设计

## 目标

把桃桃小屋收敛成纯统计页面：在现有成长卡中增加本月日历，删除与统计无关且容易挤压布局的“每日一句”和计时器，健康行为只保留喝水、活动一下、护眼、上厕所四项。

## 已确认方案

采用成长卡内双视图方案：

- 默认显示现有“7 天成长路线”。
- 卡片顶部提供“7 天 / 本月”切换。
- “本月”显示当前自然月日历，不新开页面、不弹出大型浮层。
- 点击某一天，在月历卡片内显示当天四项行为次数、专注次数、活跃时长和能量。

## 页面结构

1. 顶部保留品牌、日期、设置、统计定位和关闭。
2. 中上保留桃桃能量与今日专注、休息次数、活跃时长三项摘要。
3. 左侧保留“照顾自己就是最好的生产力”便签。
4. 中下成长卡提供“7 天 / 本月”切换。
5. 右侧删除“每日一句”便签和番茄计时器，只保留安静工作的桃屁屁。
6. 底部行为坞改为四等分：喝水、活动一下、护眼、上厕所。

## 月历设计

- 使用星期一到星期日的七列网格。
- 显示当月 1 日至最后一日；月外补位为空白，不显示虚假数据。
- 每个日期格包含日期数字、当天能量，以及四项行为状态。
- 四项行为使用与底部入口一致的颜色/微型图标语言：喝水蓝、活动绿、护眼青绿、厕所桃橙。
- 次数为 0 时降低透明度；有记录时显示实色标记和次数。
- 今天使用柔和珊瑚描边；选中日期使用奶油白浮起卡片，不采用硬边表格。
- 小窗口优先保证日期和状态标记可读，隐藏次要能量文字，不允许重叠。

## 数据设计

- Runtime 在快照中增加当前自然月的 `DailyStats[]`。
- 月份边界按本地时区计算，查询当月第一天到最后一天。
- 无记录日期使用空统计对象，分数和次数均为 0。
- 月历只读，不直接修改行为记录；点击日期只切换详情。
- 现有 7 天趋势数据和存储结构保持兼容。

## “活动一下”资产

- 将原“起身”文字改为“活动一下”。
- 使用内置 ImageGen 参考现有桃桃小屋道具风格，生成单个正在做舒展拉伸的人物。
- 造型圆润、动作清楚，3D 高级哑光磨砂/漫射材质，桃粉、奶油白与叶绿色点缀。
- 固定正面略俯视镜头，透明背景，不含文字、边框、地面和额外物体。
- 不用 HTML、CSS、SVG 或 emoji 绘制人物。

## 删除项

- 删除右侧“每日一句”入口、弹层及对应状态。
- 删除统计页右侧番茄计时器；桌宠右键和 macOS 菜单栏专注能力不受影响。
- 删除底部“休息一下”行为入口和日历道具导入。

## 响应式规则

- 删除右侧两个组件后，桌面网格改为更稳定的两区结构：主统计区 + 角色区。
- 成长卡内部自行切换折线或月历，不改变外层网格尺寸。
- 行为坞固定四列，图标在 960×650 与 1050×760 下等宽放大。
- 月历在最小窗口下仍保持七列；日期格通过字号和间距缩放，不横向滚动。

## 测试与验收

- 单元测试：自然月起止、闰年二月、空日期补零、每日四项数据映射。
- 交互测试：7 天/本月切换、日期选择、选中详情更新。
- 静态合约：页面不再渲染“每日一句”“开始专注”“休息一下”“起身”。
- 视觉实测：960×650、1050×760；文字、图标、月历日期不得重叠或越界。
- Product Design QA：与现有粉橙统计页并排比较，P0/P1/P2 清零后交付。

## 非目标

- 本轮不提供跨月份翻页。
- 不在月历中直接补录或撤销行为。
- 不修改桌宠窗口、提醒调度、专注计时核心逻辑。
