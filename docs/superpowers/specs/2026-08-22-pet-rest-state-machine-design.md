# 桃屁屁专注、休息轮播与爆炸恢复设计

## 目标

把桌宠交互收敛成一套不会互相抢状态的明确流程，同时完成以下体验：

- 平常只做安静的小动作，悬停不再随意切换视频。
- 专注时持续敲电脑，并从开始专注起累计连续工作时间。
- 每次番茄结束都用桃屁屁 IP、全屏动态大字和动画提醒活动、喝水、上厕所、护眼。
- 用户点击桃屁屁后才算正式开始休息；未点击就继续累计连续工作时间。
- 默认连续工作 40 分钟触发爆炸，阈值可设置。
- 本次休息中的行为可以即时打卡；完成项从当前动画轮播中移除，未完成项继续播放。
- 爆炸后变为扁桃并锁定专注，真实休息满 5 分钟才恢复。
- 第 4 个番茄进入长休息并播放睡觉视频。
- macOS 与 Windows 均显示专注和休息倒计时。

## 已确认的核心规则

### 连续专注

- 连续工作时间从用户开始专注时累计，不从番茄结束后重新计算。
- 番茄结束只产生休息提醒，不自动认定用户已经休息。
- 只有用户点击桃屁屁开始休息，且系统检测到用户进入休息，连续工作累计才暂停或结束。
- 爆炸阈值默认 40 分钟，在设置中允许调整。

### 每次休息都提醒四项行为

每个番茄结束都进入 `rest_due`，提醒内容固定包含：

1. 活动一下。
2. 喝水。
3. 上厕所。
4. 护眼。

四项不再按第 1、2、3 个番茄拆分。第 4 个番茄仍先展示这四项提醒，随后进入长休息睡觉状态。

### 当前休息内的打卡与轮播

- 用户点击桃屁屁开始休息后，本次休息创建四项临时待办：活动、喝水、上厕所、护眼。
- 悬停桃屁屁时，在角色头顶附近弹出四项气泡选择，不显示“撤销”“反馈”等多余按钮。
- 用户完成哪项就点击哪项；该项记录完成时间并立即从本次休息的轮播队列移除。
- 未完成项目继续轮播全屏大字和对应动画。
- 动画播放顺序由当前未完成队列决定；播放完最后一项后，从剩余队列第一项继续。
- 队列只服务于当前这次休息，不把未完成项强制带到下一次休息。
- 本次休息结束后，临时队列销毁；行为完成记录仍写入持久化统计。
- 全部完成时停止提醒轮播，桃屁屁进入安静休息动作；长休息则切换到睡觉循环。

## 状态模型

使用“唯一主状态 + 短暂覆盖层”的有限状态机。任何时候只有一个主状态可以控制角色视频。

| 主状态 | 角色表现 | 允许的主要操作 |
| --- | --- | --- |
| `idle` | 低幅度待机循环：呼吸、眨眼、轻微手脚动作 | 点击打开紧凑操作；悬停显示一句短气泡 |
| `transforming` | 完整旋风过渡 | 不接受改变主状态的重复点击 |
| `focusing` | 持续循环敲电脑，随连续工作时间逐渐变红、胀大 | 点击只显示“先专注，别分心”；可明确取消专注 |
| `rest_due` | 仍保持专注动作；首次出现全屏休息提醒 | 点击桃屁屁开始休息；不点击则继续累计并升高压力 |
| `resting` | 按当前未完成队列轮播活动、喝水、厕所、护眼动画 | 悬停显示四项打卡气泡；点击项目完成打卡 |
| `long_rest` | 第 4 个番茄的提醒队列完成后循环睡觉视频 | 悬停显示完成项与剩余休息时间 |
| `exploding` | 全屏播放爆炸瞬间和动态大字 | 暂停其他交互 |
| `deflated_locked` | 扁桃停留，提示“快去休息啦” | 只允许开始休息；禁止开始专注 |
| `recovering` | 扁桃保持安静，显示恢复倒计时 | 真实休息满 5 分钟后旋风复原 |

临时覆盖层只负责全屏大字、系统通知和短气泡，不直接改变主状态，也不能抢占正在播放的必要过渡。

## 状态转换

### 正常专注路径

1. `idle` 点击开始专注。
2. 播放完整 `transforming`。
3. 进入 `focusing` 并启动番茄倒计时、连续工作累计。
4. 番茄结束进入 `rest_due`，全屏依次出现“活动一下”“喝水”“上厕所”“放松眼睛”。
5. 用户点击桃屁屁后进入 `resting`，启动短休息倒计时和四项轮播。
6. 完成一项，该项从队列移除；剩余项继续播放。
7. 休息结束时经旋风过渡回到 `idle`；如果这是第 4 个番茄，进入 `long_rest` 并播放睡觉视频。

### 忽略休息与爆炸路径

1. 番茄结束后用户不点击桃屁屁，保持 `rest_due`。
2. 角色继续敲电脑；连续工作时间继续增长，压力视频按照时间映射逐步变红和膨胀。
3. 达到设置的连续工作阈值，默认 40 分钟，系统发送休息通知并进入 `exploding`。
4. 全屏播放爆炸瞬间和“快去休息啦”，随后进入 `deflated_locked`。
5. `deflated_locked` 禁止开始专注，所有普通点击不会恢复站姿。
6. 用户点击桃屁屁开始休息，进入 `recovering`。
7. 系统检测真实休息满 5 分钟后，播放旋风恢复并回到 `idle`。

## 点击、悬停与气泡

### 点击

- `idle`：打开紧凑操作入口，不随机改变角色状态。
- `focusing`：不退出专注，只显示短句“先专注，别分心～”。
- `rest_due`：直接确认开始休息，不再二次询问。
- `deflated_locked`：直接开始恢复休息。
- “打招呼”只在用户明确点击对应菜单项后完整播放；启动和悬停都不自动触发。

### 悬停

- 平常和专注状态只出现一句短气泡，2–3 秒自动消失。
- 休息状态出现四项打卡气泡：喝水、活动、上厕所、护眼。
- 气泡贴近桃屁屁头顶，视觉间距约 8–12px；空间不足时向另一侧翻转，不遮住主体。
- 气泡不承载撤销、反馈、取消等无关操作。

## 全屏动态提醒

- 全屏提醒使用独立透明、置顶、可穿透的短时窗口，不扩大桌宠本体窗口。
- 每次番茄结束依次显示桃屁屁 IP 和四条动态大字：
  - “起来活动一下啦！”
  - “要去喝水啦！”
  - “该去上个厕所啦！”
  - “让眼睛休息一下吧！”
- 动画以弹入、轻微回弹和淡出为主，不使用持续闪烁。
- 爆炸后显示“快去休息啦！”，同时保留扁桃角色。
- `prefers-reduced-motion` 开启时改为淡入淡出。

## 视频与透明边缘

- 待机视频使用低幅度循环，人物比例、腿长和手部造型遵循参考图。
- 专注视频持续循环敲电脑，不在循环中停住。
- 活动、喝水、厕所、护眼根据当前未完成队列依次播放。
- 睡觉视频只用于第 4 个番茄后的长休息。
- 旋风视频用于进入专注、退出专注、专注转休息和爆炸恢复；保留更多旋风尾帧，直到过渡完整后才切状态。
- 所有视频重新计算 Alpha 包围盒，以脚底或椅脚为统一底部锚点，并保留透明安全边距。
- 去除素材自身的白边、灰底和底部横向阴影；运行时不再添加会被透明窗口裁切的深色投影。
- 视频切换不改变媒体容器尺寸，避免角色突然变大或缩小。

## 计时与设置

设置项包含：

- 番茄专注时长，默认 25 分钟。
- 连续工作爆炸阈值，默认 40 分钟。
- 短休息时长，默认 5 分钟。
- 长休息时长，默认 15 分钟。
- 长休息周期，默认每 4 个完整番茄一次。

macOS 菜单栏同时显示专注和休息倒计时；Windows 使用任务栏进度和托盘提示显示当前阶段与剩余时间。桌宠本体不常驻显示倒计时，悬停时才在短气泡显示。

## 统计与持久化

- 前端删除月视图与无效的右上角统计按钮，只展示每周统计。
- 月度与每日明细继续在本地数据库保存，但不在本轮界面中呈现。
- 记录用户在每个主状态中的实际停留时长：平常、专注、待休息、短休息、长休息、爆炸锁定和恢复。
- 每次状态切换都写入一条可追溯的使用区间，包含状态、开始时间、结束时间和持续秒数；应用异常退出后用最后持久化时间补齐区间，避免只依赖内存计数。
- 四项健康行为同时记录完成时间，以及从本次休息开始到完成打卡的等待秒数；这表示完成响应时间，不虚构用户实际喝水或上厕所花了多久。
- 每日与每周统计汇总各状态时长；原始区间继续保留，后续可扩展月度分析。
- 持久化内容包括：番茄阶段、连续工作起点、爆炸阈值、短/长休息时长、当前第几个番茄、爆炸锁定状态、恢复开始时间、每日四项行为完成记录和周统计。
- 应用异常退出或重启后，根据墙上时钟重建剩余时间，不能通过重启绕过爆炸锁定或恢复要求。
- 当前休息的临时四项轮播队列可在进程内保存；若休息期间重启，则根据该次休息已经记录的行为重建剩余队列。

## APP 图标

- 使用内置 ImageGen 参考桃屁屁原始设定重新生成，不用 HTML、CSS、SVG 或 emoji 绘制角色。
- 方向：透明背景、简约轮廓、粉橙桃体与草地绿叶片、3D 漫射哑光材质、轻质感、高级、低 AI 感。
- 图标不使用站立全身构图，改为更适合小尺寸识别的桃形主体与叶片负形组合。
- 输出 1024×1024 透明 PNG 母版，并生成 macOS `.icns` 与 Windows `.ico`。
- 在 16、32、64、128、256、512px 下检查轮廓、叶片和表情可辨识度。

## 能量区视觉修正

- 删除会与数字重叠的生成式半圆能量弧图片，不再把可变数据叠在不可控图片内部。
- 改为真正的响应式进度组件：标题、能量数字、说明文字和进度条各占独立布局行，任何窗口尺寸都不互相覆盖。
- 进度条使用简约奶油色轨道、明亮桃橙色进度和叶绿色完成点缀；只使用稳定的 UI 组件表达数据，不用 HTML/CSS 仿造角色或插画。
- 当日能量没有最高分时，进度条表示“今日基础目标”的完成度，默认目标 100；超过目标后保持满格并在数字旁显示超出值，原始分数继续无上限增长。
- 960×650、1050×760、1400×800 三档窗口下，能量数字、标题、进度条和三项摘要都必须保持安全间距。

## 验收标准

- 悬停不会改变角色主状态；专注点击不会退回站姿。
- 只有明确点击“打招呼”才播放完整问候视频。
- 每次番茄结束都出现四项全屏提醒。
- 未点击开始休息时，连续工作时间持续累计；默认 40 分钟触发爆炸。
- 休息时完成一项，该项立即从本次轮播移除；未完成项继续循环。
- 第 4 个番茄长休息播放睡觉视频。
- 爆炸后禁止专注，真实休息不足 5 分钟不能恢复。
- 气泡与角色距离自然，不遮挡角色；四项在最小桌宠窗口下可读可点。
- 视频脚部、椅脚和道具完整，无底部横线、白边、灰底或尺寸跳变。
- macOS 菜单栏与 Windows 托盘/任务栏都能显示专注和休息倒计时。
- 周统计可正常展示；月度数据继续保存但月视图不可见。
- 每一种主状态的开始、结束与持续时间均可在数据库中查询，并正确汇总到每日和每周数据。
- 能量区使用真实响应式进度条，标题、数字、说明和进度条在所有验收窗口中不重叠。
- macOS 与 Windows 安装包均使用新图标。

## 非目标

- 本轮不加入大模型对话。
- 不要求每项行为单独打开页面。
- 不在统计页恢复月历展示。
- 不把未完成的临时休息队列强制延续到下一次休息。
