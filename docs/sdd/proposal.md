# 桃屁屁 2.0 Proposal / PRD

## 1. 产品定位

桃屁屁是一款面向程序员的本地健康陪伴桌宠。它不靠频繁弹窗打断用户，而是用角色状态、系统栏倒计时和轻量互动提醒喝水、起身、护眼、上厕所与番茄休息。

本轮目标不是只改统计页，而是完成一套“视频驱动桌宠 + 健康能量机制 + 系统级计时 + 桃桃小屋统计页”的可运行 MVP。

## 2. 当前问题

- 原项目已有多段固定镜头动作视频，但旧版本主要切换静态 PNG 并持续摇摆，浪费素材且容易分散注意力。
- 视频去背后尺寸、主体位置和首尾帧不统一，悬停切换时会产生突然缩小、抽帧或循环断裂。
- 宠物底部常驻计时与操作条显得拥挤；右键一次展开全部功能也增加认知负担。
- 统计页实现比设计稿更暗、更散，桃色主角不突出，字号和文字边界不稳定。
- 健康分从 100 开始或单纯工作就加分，没有“照顾自己才能养好桃屁屁”的目标感。

## 3. 用户目标

1. 专注时看到桃屁屁安静、持续地敲电脑；普通待机只做低频小动作，不被大幅动作吸引。
2. 不打开设置页也能从系统栏或悬停气泡查看倒计时。
3. 通过点击、悬停打卡或分级系统右键菜单完成高频操作，桌宠默认保持小尺寸。
4. 久坐时直观看到桃屁屁变红、变胀，继续忽略会触发全屏爆炸。
5. 在“桃桃小屋”里快速理解今天和最近 7 天的健康情况。

## 4. MVP 范围

### 4.1 视频桌宠

- 使用用户提供的挥手、变身、厕所、专注敲电脑、睡觉、干裂恢复和膨胀爆炸等 MP4，并补充一致风格的待机、活动和护眼动作。
- 通过 `rembg + VP9 Alpha WebM` 形成透明桌宠视频。
- 完整挥手只在用户明确选择“打招呼”后播放一次；启动和悬停不自动播放。待机仅循环低频小动作。
- 专注视频只循环低动作片段，并裁掉导致跳变的尾帧。
- 所有视频使用同一可视边界、锚点与角色高度，状态切换不能突然缩放。

### 4.2 番茄钟与提醒

- 宠物下方不常驻倒计时或工具条。
- macOS 菜单栏显示倒计时；Windows 任务栏显示进度，托盘显示完整时间。
- 专注时悬停宠物，用角色气泡说出剩余时间。
- 番茄结束后点击桃屁屁确认开始休息；每次休息都轮播活动、喝水、厕所和护眼，打卡后立即移除已完成项。第 4 个番茄完成四项后才播放睡觉长休。

### 4.3 压力、爆炸与恢复

- 随连续活跃时长增加，桃屁屁逐渐变红、变大、表现不舒服。
- 达到阈值后在当前屏幕播放全屏透明爆炸。
- 爆炸视频只保留“桃子爆开”的有效瞬间；爆开后的椅子及静止尾帧必须裁掉或遮除。
- 爆炸后进入瘪气锁定状态；必须开始休息并累计至少 5 分钟有效休息，恢复到 100 后才允许重新专注。

### 4.4 操作模型

- 左键：响应当前提醒、确认开始休息或轻互动。
- 悬停：显示状态/剩余时间；休息中显示本次尚未完成的四项打卡，不自动播放完整问候。
- 右键第一层只展示“专注计时”“记录健康行为”“打招呼”“桃桃小屋与设置”；专注与健康行为使用系统子菜单。
- 默认宠物尺寸约 140px，兼容历史设置但不再暴露尺寸选择；系统菜单使用固定可读尺寸。

### 4.5 桃桃小屋统计页

- 参考 `exec-fa04e291-294c-46bf-bc47-a82186114145.png`，采用粉桃、珊瑚橙、叶绿和奶油白。
- 桃子和关键数据提高饱和度与对比度，背景保持温暖但不能压过主体。
- 建立明确字号层级和安全边距，文字不得溢出生成图边界。
- 删除会干扰排版的“每日一句”、月视图和页面内计时器，当前只展示最近 7 天趋势；更长历史仍保存在本地。
- 图像元素全部使用独立生成资产，不用 HTML/CSS/SVG 仿造角色或 3D 道具。

## 5. 能量规则

- 每天从 0 分开始，总分不设最高值；连续工作本身不加分。
- 完成健康行为和有效休息才能补充能量。
- 忽略提醒或爆炸扣分；当天爆炸次数越多，扣分越重。
- 100 是基础成长目标而不是分数封顶；不同健康行为使用不同权重和每日防刷上限。

## 6. 非目标

- 本阶段不接入轻量大模型聊天。
- 不重做用户原视频中的角色造型。
- 不让用户端安装 `rembg`；生成后的 WebM 随应用交付。
- Windows 原生安装与系统栏表现需要 Windows 实机或 CI 最终验收。

## 7. 成功标准

- 用户视频与补充动作全部进入实际状态机，不再只有图片晃动。
- 待机低频微动；问候仅点击单次播放；专注和睡觉循环无明显首尾割裂。
- 状态切换时主体视觉尺寸误差不超过 5%，不出现悬停突然变小。
- 爆炸覆盖当前屏幕，只保留有效爆开段，结尾无椅子残留。
- 倒计时不常驻宠物底部，Mac/Windows/悬停入口符合平台规则。
- 右键菜单分级打开，系统菜单与宠物尺寸互不影响。
- 统计页在最小窗口尺寸下无文字溢出，桃子主体比当前实现更鲜艳醒目。
- 视频处理方法、时间段和新增素材步骤均可由文档复现。
