# 桃屁屁 2.0 Proposal

## 背景

MVP 已实现透明置顶桌宠、番茄钟、健康提醒、爆炸扣分和统计，但角色表现主要依赖静态 PNG 切换与 CSS 摇摆。原项目中已有 5 段完整动作视频，却没有进入运行时，导致动作单调、专注时干扰明显、已有素材价值没有发挥。

## 目标

1. 将原始视频转换为桌宠可直接播放的透明动效，核心状态优先使用视频。
2. 缩小桌宠默认尺寸，并允许用户在宠物内快速调节大小。
3. 移除桌宠底部常驻计时工具条：macOS 使用菜单栏倒计时，Windows 使用任务栏/托盘状态；桌宠悬停时显示剩余时间。
4. 把所有高频操作收回桌宠的点击、悬停和右键菜单，统计页只承担回顾作用。
5. 健康分每日从 50 开始，靠健康行为提升到 100；单纯持续工作不加分。
6. 将统计页重做为低密度、卡通健康手账风，并保证数据仍来自本地 SQLite。

## 非目标

- 本阶段不增加大模型聊天。
- 不重新生成已有视频中的角色。
- 不把所有白底视频逐帧人工修图；采用可复现的透明视频转码流程。
- Windows 原生安装包仍需在 Windows 或 Windows CI 上最终验证。

## 成功标准

- 待机不再持续上下晃动。
- 挥手、专注敲电脑、睡觉、厕所、膨胀爆炸均来自用户原始视频。
- 默认桌宠视觉尺寸约 190px，可在 140–280px 范围内调节并持久化。
- 番茄倒计时不在宠物底部常驻；悬停和系统栏可查看。
- 爆炸动效扩展到当前屏幕，结束后回到瘪气状态。
- 每日分数从 50 开始，健康行为加分，久坐/忽略提醒扣分。
- 统计页使用统一桃粉、叶绿、奶油白的卡通化视觉系统。
