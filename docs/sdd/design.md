# 桃屁屁 2.0 Design

## 1. 视频素材映射

| 标准名 | 用户原视频 | 运行状态 | 播放策略 |
| --- | --- | --- | --- |
| `greeting` | `2457…打招呼.mp4` | 用户明确选择“打招呼” | 完整单次播放，结束停回待机，不循环 |
| `toilet` | `6419…飞奔…厕所.mp4` | 完成厕所提醒 | 单次播放，结束回当前主状态 |
| `focus` | `6475…坐在凳子上…电脑.mp4` | 专注 | 仅循环安静敲电脑片段，裁掉接缝尾帧 |
| `sleep` | `9784…睡觉.mp4` | 第 4 个番茄且四项提醒均完成后的长休息 | 循环稳定睡眠段，避开动作重置帧 |
| `pressure` | `9810…坐着…爆炸.mp4` | 压力预警、全屏爆炸 | 前段按压力定位；爆炸只播放爆开瞬间 |
| `transform` | `4702…跳起来飞速旋转.mp4` | 开始/取消专注、恢复正常 | 单次播放至 9.82 秒，保留完整旋风尾部；以 1.55 倍速进入下一状态 |
| `dry` / `hydrating` | `1782…一直站着…干裂.mp4` | 超时喝水提醒 / 确认喝水 | 前 1.45 秒停在干裂；确认后播放 1.45–9.90 秒恢复 |

原始 MP4 位于 `assets/video/source/`，透明 WebM 位于 `assets/video/generated/`；时间元数据在 `assets/video/manifest.json`。完整处理方法见 `docs/video-asset-workflow.md`。

## 2. 视频标准化

### 2.1 去背与编码

1. FFmpeg 抽帧并统一帧率和工作宽度。
2. `rembg` 的 `u2netp` 模型逐帧生成 Alpha，保留主体和必要道具。
3. 对每段素材计算非透明像素包围盒，按脚底/椅脚基线建立统一锚点。
4. 放入固定透明画布，角色可视高度统一，避免悬停切换时突然变小。
5. 编码为无音轨 VP9 `yuva420p` WebM，关闭 `auto-alt-ref` 以保留 Alpha。

运行时不通过 CSS 改变视频本体尺寸来模拟状态；角色膨胀只由压力动作或统一容器中的受控缩放完成。

### 2.2 裁头尾和爆炸

- 问候：去掉动作开始前和结束后相似的停顿帧，单次播放后回待机。
- 专注/睡觉：用相邻帧差寻找动作最接近的首尾点；循环结束点必须早于明显“回到开场姿势”的帧。
- 压力：前段用于压力预览；全屏爆炸从桃体破裂前数帧开始，到爆裂主体离开/收缩完成前结束。
- 最后一帧若只剩椅子，不进入正式文件。若椅子与爆裂瞬间重叠，则逐帧遮罩椅子区域后重新编码。

## 3. 角色状态机

视觉优先级：`exploding → deflated/recovering → 当次休息轮播 → pressure → transform → focus → greeting → idle`。

- `idle`：低频眨眼、手脚和小表情；主体大小与脚底基线固定，不使用持续 CSS 缩放或摇摆。
- `greeting`：只有用户从系统右键菜单明确选择“打招呼”才完整播放一次；启动和悬停都不自动触发。播放完成自动恢复上一个主状态。
- `transform`：专注开始、取消或瘪气恢复时完整播放跳起、旋转和旋风，再进入对应主状态；运行时覆盖时长必须覆盖 1.55 倍速后的完整片段。
- `focus`：安静、持续循环地敲电脑。点击只显示“保持专注”，绝不切回站姿。
- `pressure`：压力 55 以上进入，按压力值映射到变红/膨胀进度，不循环完整爆炸段。
- `rest_due`：番茄结束后继续保持当前专注动作，并显示全屏休息提醒；必须点击桃屁屁才开始休息。
- `short_break/long_break`：进入休息后按 `活动一下 → 喝水 → 上厕所 → 护眼` 轮播当前仍未完成的动作。每段先完整播放，打卡当前项可立即切换到下一未完成项。第 4 个番茄也先完成四项，全部完成后才播放睡觉长休。
- `reminder`：用置顶短气泡提示；水提醒显示 15 分钟仍未确认时，切换为干裂并停住。确认喝水后才播放恢复段；护眼逾期 10 分钟进入红眼干裂警示。
- `exploding`：独立全屏透明窗口仅播放爆开段和扣分提示。
- `deflated/recovering`：爆炸结束回瘪气小窗并锁定新专注；点击开始休息后累计至少 5 分钟有效休息，恢复到 100 才播放变身并解除锁定。

状态切换使用短淡入淡出，但媒体容器尺寸和底部锚点保持不变。`prefers-reduced-motion` 下关闭自动悬停问候，只保留必要状态动作。

## 4. 桌宠窗口与交互

### 4.1 尺寸

- 默认角色约 140px；兼容旧设置时最小为 120px。透明窗口额外预留气泡区，不缩放角色来为文字让位；脚、椅脚和道具必须完整露出。
- MVP 不提供尺寸选择，避免桌宠和系统菜单被误缩放。
- 右键菜单放在独立固定尺寸浮层或独立窗口；空间不足时自动翻转到另一侧。

### 4.2 左键和悬停

- 番茄结束待确认：左键只用于确认“现在开始休息”，随后建立本次四项轮播。
- 休息中悬停：显示喝水、活动一下、上厕所、护眼四项中尚未完成的按钮；点击即打卡并从本次轮播移除。
- 未完成项不推迟到下一次休息，而是在本次休息中继续按各自完整视频时长轮播。
- 无待处理事项：左键只做短互动。
- 专注中悬停：气泡文案为“还剩 24:18，我陪你一起完成”。
- 非专注悬停：只显示当前状态短句，不自动播放完整问候。
- 气泡出现约 3.2 秒后自动隐藏，即使鼠标仍停留也不延长；倒计时绝不放在宠物底部。

### 4.3 分级右键菜单

第一层保持 4–6 个清晰入口：

| 一级入口 | 二级内容 |
| --- | --- |
| 专注计时 | 25/45/60 分钟、开始/暂停/继续、取消专注 |
| 记录健康行为 | 喝水、活动一下、护眼、上厕所 |
| 打招呼 | 完整播放一次问候视频 |
| 桃桃小屋与设置 | 打开统计页和节奏设置 |

专注计时和健康行为使用系统原生子菜单，指针离开即可返回一级；Esc 关闭菜单。菜单字体和点击区固定，不跟随宠物缩小。

## 5. 倒计时与平台适配

- macOS：托盘/菜单栏标题显示 `24:18`；暂停时显示暂停标识，非专注时隐藏时间。系统菜单栏字体由系统控制，应用选择短、粗、易辨认的数字排版。
- Windows：任务栏进度反映完成比例；托盘悬停显示“桃屁屁 · 专注剩余 24:18”。如数字叠加图标可读性不足，以托盘提示为正式降级方案。
- 桌宠：专注时悬停气泡显示剩余时间。

## 6. 能量、压力与恢复

每天首次启动或跨日从 0 分开始，没有总分上限。专注时长只进入统计，不直接奖励分数；重复行为仅在各自每日次数内奖励，避免误点无限加分。

| 行为 | 分数 | 压力变化 |
| --- | ---: | ---: |
| 喝水 / 护眼 / 厕所 | +8 / +5 / +6 | 最多 -20 |
| 起身活动 | +12 | 最多 -20 |
| 完成有效番茄休息 | +10 | 最多 -20 |
| 键鼠空闲满 3 分钟 | +0 | 最多 -20 |
| 忽略提醒 | -3 | +10 |
| 当日第 1 / 2 / 3 次爆炸 | -15 / -30 / -50 | 清空压力并进入瘪气 |

瘪气时恢复值为 0，并锁定新的专注。用户点击开始休息后，系统按真实空闲时间累计；连续有效休息满 5 分钟时恢复值一次达到 100，播放恢复变身并解除锁定。健康行为仍正常记录，但不能替代这 5 分钟真实休息。

内部保留一次性回滚数据能力用于兼容，但按最终交互要求不在气泡或右键菜单展示“撤销/稍后”等操作，避免把一句提醒变成复杂表单。

每个番茄结束都必须通过桌宠确认休息；本次休息固定创建四项健康队列。连续专注压力从用户点击开始专注时累计，达到设置上限（默认 40 分钟）触发爆炸，不因一个番茄自然结束而隐式归零。

## 7. 桃桃小屋视觉与排版

### 7.1 色彩

- 主桃色：提高明度和饱和度，用于角色、数字和交互重点。
- 珊瑚橙：用于能量弧、趋势线、激活状态。
- 叶绿：用于健康完成、能量增长和叶片。
- 奶油白：用于文字承载层和模态内容。
- 房间背景降低约一个对比层级，避免与角色争抢注意力。

所有文本与承载面至少满足可读对比度；不在复杂生成图上直接放小号正文。

### 7.2 字号层级与安全区

- 能量数字：64–88px；页面主标题：30–36px；区块标题：22–26px。
- 关键指标：32–44px；正文：17–20px；辅助说明不低于 14px。
- 生成图仅作为背景或独立图像元素；文字放在可控的布局容器中。
- 任何文字距离资产边缘至少 20px，窗口缩小时允许换行或隐藏次要说明，不允许溢出。

### 7.3 页面结构

1. 左上品牌；右上日期和低频入口。
2. 中上能量弧与大号分数。
3. 其下为今日专注、休息、活跃三项摘要。
4. 中下为最近 7 天健康成长卡；月度明细继续记录在 SQLite 中，但按当前 MVP 决策不在前台展示。
5. 底部只保留喝水、活动一下、护眼、上厕所四项健康行为；不再额外放置通用休息入口。
6. 右侧统计页角色只在首次进入或指针悬停时播放一次动作；桌面待机角色使用低频小动作循环。
7. 统计页删除“每日一句”和番茄计时器；专注计时继续由桌宠右键菜单、macOS 菜单栏和 Windows 任务栏承载。

### 7.4 响应式约束

- 页面主体使用一个三列四行的 CSS Grid；品牌栏、能量区、鼓励便签、成长卡、角色和四项行为坞都有固定 `grid-area`，禁止各自用百分比绝对定位争抢空间。
- 能量标题、分数、当日说明和三项指标分别占独立网格行；标题永远位于能量弧上方，不与顶部叶片相交。
- 7 天趋势图的父容器随网格单元伸缩，图表宽高均使用响应式容器重新计算，窗口改变后折线和节点同步重排。
- Electron 窗口负责最小尺寸保护；页面内部不再重复设置大于内容区的固定最小高度，避免标题栏占高后底部被裁掉。
- 每个健康行为按钮预留 24px 的固定名称行，图片只能在剩余区域内缩放，文字和计数不得溢出行为坞。
- 视觉验收覆盖 `960 × 650`、`1050 × 760`、`1400 × 800` 三档逻辑窗口尺寸。

## 9. 数据与降级

- SQLite 继续保存设置、行为事件、提醒响应时间、运行时快照和每种状态的持续时长；7 天界面只是本地完整历史数据的当前展示窗口。
- 视频加载失败时回退到对应透明 PNG，并记录素材失败事件。
- 护眼提醒超过 10 分钟未确认，切换到四级眼睛发红/干裂动作并停在最后一帧；普通护眼提醒仍使用轻度护眼姿态。
- 桌宠气泡是短时语句层，不是操作卡：无完成、稍后、撤销或取消按钮，3.2 秒自动隐藏；专注悬停只显示剩余时间，专注点击只显示“保持专注”。
- Alpha WebM 不兼容时回退 PNG，不显示白/灰色矩形视频背景。
- 全屏爆炸窗口无论正常结束或异常关闭，都必须恢复小窗可交互状态。

## 10. 验收测试矩阵

- 单元：0 分跨日重置、所有加扣分、瘪气恢复、状态优先级、使用时长跨午夜切分、重启恢复、菜单动作。
- 素材：全部 WebM 存在、VP9 Alpha、无音轨、时间段合法、统一包围盒，并抽取开始/中间/结束帧检查底部残影和循环首尾差。
- 视觉：首尾接缝、悬停尺寸一致、椅子尾帧、文本溢出、最小窗口布局。
- 集成：专注→完成→点击休息→睡觉；压力→爆炸→瘪气→恢复。
- macOS：透明置顶、多桌面、菜单栏倒计时、缩放、全屏爆炸。
- Windows：透明窗口、任务栏进度、托盘倒计时、安装/卸载。
