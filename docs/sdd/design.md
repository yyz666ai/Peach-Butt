# 桃屁屁 2.0 Design

## 1. 素材盘点与映射

| 原始视频 | 时长 | 运行状态 | 播放方式 |
| --- | ---: | --- | --- |
| `2457…打招呼.mp4` | 10.08s | 初始化、空闲悬停、点击问候 | 单次播放，结束返回待机 |
| `6419…飞奔…厕所.mp4` | 7.10s | 上厕所提醒完成 | 单次播放 |
| `6475…坐在凳子上…电脑.mp4` | 10.08s | 专注工作 | 选取低动作片段无缝循环 |
| `9784…睡觉.mp4` | 5.09s | 番茄休息、有效休息 | 循环播放 |
| `9810…坐着…爆炸.mp4` | 7.10s | 压力预警、全屏爆炸 | 前段按压力定位，结尾全屏播放 |

视频统一转为 24fps、无音轨、VP9 Alpha WebM。白色固定背景通过色键和边缘羽化去除，输出后检查透明通道、时长和首尾帧。原始 MP4 保留，便于以后重新调参。

## 2. 角色状态机

优先级从高到低：`exploding → deflated → reminder → break → pressure-warning → focus → greeting → idle`。

- `idle`：透明 PNG 静止待机，仅保留非常轻微的眨眼视频机会，不再通过 CSS 持续位移。
- `greeting`：鼠标进入角色命中区域时播放挥手视频；30 秒冷却，避免频繁打断。
- `focus`：播放坐着敲电脑视频的低动作循环段。悬停显示剩余时间；离开后隐藏。
- `pressure-warning`：压力超过 55 后切换到膨胀视频前段，并按压力值定位播放时间，角色逐渐变红、变大、不舒服。
- `break`：番茄结束后点击角色确认休息，循环播放睡觉视频。
- `reminder`：提醒气泡只在到期时出现；完成厕所提醒播放厕所视频，其余动作使用透明图片兜底。
- `exploding`：压力达到 100，临时全屏透明窗口播放爆炸结尾并显示大号扣分反馈。
- `deflated`：全屏窗口结束后恢复小窗口，显示瘪气图。完成喝水、活动、休息或下一次有效番茄休息时逐步恢复。

状态切换采用 180ms 交叉淡化。视频动作本身不再叠加装饰性晃动。

## 3. 桌宠窗口和操作

- 默认窗口约 `210 × 230`，角色视觉宽度约 190px。
- 设置支持 140–280px，拖动滑杆实时预览并写入本地设置。
- 左键单击：完成当前提醒或触发问候；番茄结束等待休息时用于确认。
- 悬停：显示简短状态气泡；专注时显示剩余时间。
- 右键：打开宠物旁的卡通浮层，包含开始/暂停番茄、25/45/自定义时长、健康行为、尺寸滑杆、打开统计、隐藏和退出。
- 拖动：按住角色移动；拖动阈值 5px，避免误触发点击。
- macOS：菜单栏显示 `24:18` 等倒计时。
- Windows：任务栏使用进度与数字叠加图标，托盘提示完整倒计时。

## 4. 压力与积分

每天首次启动或跨日时健康分重置为 50，范围 0–100。连续工作本身不奖励分数。

| 行为 | 分数 | 压力变化 |
| --- | ---: | ---: |
| 完成喝水/护眼/厕所 | +5 | -12 |
| 完成起身活动 | +8 | -20 |
| 完成一次有效番茄休息 | +8 | -25 |
| 离开键鼠满 3 分钟 | +3（每日最多 5 次） | -15 |
| 忽略提醒 | -3 | +10 |
| 第 1/2/3 次爆炸 | -15/-25/-40 | 清零后进入瘪气 |

瘪气恢复分为三档：每完成一次健康行为增加恢复值；达到 33/66/100 时分别使用膨胀一级、正常待机状态，形成“照顾它才恢复”的反馈。

## 5. 卡通统计页

视觉方向为“桃子健康手账”：奶油白画布、桃粉主色、叶绿奖励色、圆润描边卡片、轻量黏土阴影。避免传统后台式侧栏和四块无差别指标卡。

页面结构：

1. 顶部为今日桃桃能量（50–100）与一句状态总结。
2. 第一行用 3 个贴纸卡展示专注、有效休息和屏幕活跃。
3. 中部主图只保留一张 7 天健康分/活跃趋势，可切换指标。
4. 右侧为今天的健康任务清单和角色恢复进度。
5. 设置收进角色右键菜单；统计页只保留低频高级设置入口。

图表提供明确单位、悬停精确值、空数据说明和文字摘要；不只依赖红绿颜色表达好坏。

## 6. 数据与模块

- `motion-assets`：视频元数据、循环区间、透明转码结果与校验脚本。
- `pet-state-machine`：根据健康、番茄、提醒和交互计算唯一视觉状态。
- `window-manager`：小窗尺寸、位置、全屏爆炸窗口和跨平台系统栏。
- `health-engine`：50 分起始、行为得失分、压力和瘪气恢复值。
- `pet-ui`：视频播放器、图片兜底、气泡和右键操作面板。
- `dashboard-ui`：卡通统计手账。

数据继续只保存在 SQLite；新增 `petScale`、`customWorkMinutes`、`recovery` 和 `restRewardCount` 设置/运行字段。

## 7. 错误处理与降级

- WebM 加载失败时自动回退到对应 PNG，并记录本地事件。
- 不支持 Alpha WebM 的环境使用带裁剪白底的视频容器，Windows 打包验证时优先检查。
- 全屏爆炸窗口异常关闭时必须恢复小窗和可交互状态。
- `prefers-reduced-motion` 开启时不自动播放问候，仅播放必要的状态视频并降低切换频率。

## 8. 测试

- 单元测试：50 分日重置、加扣分、恢复值、状态优先级、缩放范围、循环区间。
- 素材测试：5 个 WebM 文件存在、Alpha 标记、无音轨、24fps、时长合法。
- 集成测试：专注→提醒→点击休息→睡觉→完成；压力→全屏爆炸→瘪气→行为恢复。
- Mac 实机：透明背景、菜单栏计时、悬停气泡、右键菜单、缩放、全屏爆炸。
- Windows 验证清单：透明窗口、任务栏进度/叠加图标、托盘、安装与卸载。
