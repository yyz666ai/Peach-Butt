## 2. 分工决策：程序动画 vs 视频

### 2.1 用程序做（不拍视频，完美循环，零素材成本）

| 动作 | 程序方案 |
|---|---|
| idle_breath 呼吸漂浮 | scale 1.0↔1.05 正弦 + 上下位移 ±3px |

## 3. 即梦提示词（可直接复制）

### 3.1 角色模板（每条开头都用它，锁形象）

> 这是我的原创 IP 角色「桃屁屁」：一只 3D 软糖质感的卡通宠物，身体是一颗圆润的粉色渐变蜜桃（顶部浅、底部深粉），同时又像可爱的屁股，整体像一只吹起来的气球。头顶有两片绿色叶子和一个气球结状的小蒂，黑色简笔画风格的小短手和小短腿，豆豆眼、微笑小嘴、圆腮红。圆润、Q 弹、治愈系。

### 3.2 背景与镜头后缀（每条结尾都加上）

> 纯浅灰色背景（#EEEEEE），背景无任何渐变、无阴影、无倒影、无道具，画面中只有桃屁屁一个主体。固定镜头，相机不移动不推拉，平视角度，全身完整入画，角色居中，角色全程不走出画面。

> ⚠️ **不要用绿幕**——桃屁屁头顶是绿叶，绿幕抠图会把叶子抠掉。浅灰/纯白背景 + AI 抠图（rembg）即可。
> ⚠️ 循环类动作（loop）统一在动作描述末尾加：**「动作结束时回到起始姿势，首尾姿势一致，可无缝循环」**。

## 4. 素材管线提醒

1. 视频时长选 **5s** 就够（loop 类 3–4s 净内容 + 首尾对齐），别选 10s，抽帧和体积都翻倍。
2. 拍完后管线：`ffmpeg 抽帧（12–15fps 够用）→ rembg 抠图 → 裁切对齐 → APNG/WebP 打包`，见 docs/03。
3. 每条动作抽帧后检查：①角色有没有出画 ②首尾帧姿势差多少（差距大就 ping-pong 播放兜底）③绿叶有没有被抠坏。
4. **爆炸的碎片粒子、肿胀的三档变大，都走程序**，不要试图让即梦生成——膨胀系列角色一致性最难控制，程序缩放反而 100% 一致。
