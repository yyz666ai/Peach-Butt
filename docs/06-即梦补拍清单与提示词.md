## 3. 拍摄约定（与已验证管线一致）

### 3.1 角色模板（每条提示词开头，锁形象）

> 一只圆润可爱的 3D 卡通宠物「桃屁屁」，外形是一颗蜜桃，又像可爱的屁股，也像一只粉色气球。身体是光滑的粉色渐变（顶部浅桃粉、底部桃子红），正面有一道桃子自然凹缝，顶部有绿色打结的果蒂和几片浅绿叶子，底部有 Q 版黑色小短手、小短腿，大大的深棕色圆眼睛、小腮红、小嘴巴，表情生动可爱。3D 盲盒玩偶质感，漫射哑光材质，柔和一致光照，配色为粉色 #FFB6C1 系 + 桃子红 + 浅绿叶子点缀。

### 3.2 固定镜头 + 绿幕后缀（每条结尾粘贴）

> 固定镜头、固定机位，正面略俯视角度，机位全程不移动、不缩放、不旋转；角色始终居中，全身完整入画，头顶、手、脚不裁切。纯色纯绿背景，chroma key 绿幕背景，画面中只有角色一个主体，无其他物体，无文字，无水印，无阴影，无地面，无多余道具（动作需要的除外）。

> 说明：管线用 rembg（AI 抠图）去背，绿幕只是让它更容易分离，**不会把绿叶抠掉**，happy/rest 已验证通过。
> 时长选 5~8 秒即可；循环类动作选中间 2~3 秒稳定段做循环段。

## 5. 拿到视频后的接入流程

1. 原视频放 `assets/video/source/`，用短英文名命名（如 `bored.mp4`）。
2. 跑管线（rembg 去背 → 480×500 透明画布 → 底部锚点 → VP9 Alpha WebM）：

   ```bash
   .venv-video/bin/python scripts/build-transparent-videos.py \
     assets/video/source assets/video/generated --only bored --only pet
   ```

3. `assets/video/manifest.json` 加 clip 条目（含循环时间段）。
4. `src/renderer/src/components/pet-motion-timeline.ts` 加 ClipTimeline。
5. `src/renderer/src/components/PetMotion.tsx` import 并注册到 clips 表。
6. 校验：`npm run videos:check` + `npm test`。

详细管线说明见 `docs/video-asset-workflow.md`；happy/rest 的完整接入案例见 `docs/assets/motion-prompts-new.md`。

## 6. MiniMax-H3 直连生成（已跑通，推荐替代即梦手动拍）

2026-08-30 已验证：用 H3 的「图生视频」模式（参考图 + 首帧），直接从一张角色姿势图生成动作视频，形象一致性远好于纯文生视频。

### 6.1 API 要点

- 端点：`POST https://api.minimaxi.com/v2/video_generation`（Bearer 鉴权，key 存在项目根 `.env` 的 `MINIMAX_API_KEY`，勿提交）
- 模型：`MiniMax-H3`（支持 768P/2K、4~15 秒、参考图 first_frame / reference_image）
- content 数组：`{"type":"text","text":提示词}` + `{"type":"image_url","image_url":{"url":"图片URL或base64 data URI"},"role":"first_frame"}`
- 异步任务：创建返回 `task_id`，轮询 `GET /v2/query/video_generation/{task_id}`，`succeeded` 后 `task.content.url` 下载
- 实测：5 秒 768P 约 2~3 分钟出片，输出 768×1024 竖版 @ 24fps

### 6.2 生成提示词写法（eye-strain 实测有效）

> 参考图中的粉色桃子卡通角色（头顶两片绿叶和短藤、细黑线手臂和腿、圆润屁屁形身体）感觉眼睛疲劳干涩：它慢慢抬起两只小手揉眼睛，眼睛半眯、微微皱眉，身体轻轻摇晃，表情疲惫又委屈。动作缓慢轻柔，固定镜头，全身居中，纯白色背景无阴影，3D卡通黏土渲染风格，角色形象与参考图保持完全一致。

要点：先描述参考图里的角色（帮模型锁定形象），再描述动作，结尾固定镜头 + 全身 + 纯色背景 + 「与参考图保持完全一致」。

### 6.3 高画质接入管线（2026-08-30 起为新默认）

旧素材糊的三个原因：抠图前缩到 560px、60fps 砍到 12fps、u2netp 粗模型 + 关闭 alpha matting。`scripts/build-transparent-videos.py` 已改为：

- **模型**：`isnet-general-use`（替代 u2netp）+ `alpha_matting=True`（边缘精细）
- **分辨率**：抠图前保持 ≥1024px 宽，归一化到 480×500 后依然锐利
- **帧率**：默认 24fps（manifest 里 per-clip `fps` 字段声明，校验器和契约测试已支持 12/24 混合）
- **编码**：CRF 31 → 24

新 H3 视频接入示例（eye-strain 已跑通）：

```bash
# 1. H3 生成的 mp4 放 assets/video/source/
# 2. 单条重建
.venv-video/bin/python scripts/build-transparent-videos.py \
  assets/video/source assets/video/generated --only eye-strain-h3
# 3. manifest 里对应 clip 加 "fps": 24，跑 npm run videos:check && npm test
```

对比图：`assets/generated/source/eyestrain-quality-compare.png`（灰底上左旧右新，边缘差异一目了然）。
