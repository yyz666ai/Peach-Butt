## 3. 拍摄约定（与已验证管线一致）

### 3.1 角色模板（每条提示词开头，锁形象）

> 一只圆润可爱的 3D 卡通宠物「桃屁屁」，外形是一颗蜜桃，又像可爱的屁股，也像一只粉色气球。身体是光滑的粉色渐变（顶部浅桃粉、底部桃子红），正面有一道桃子自然凹缝，顶部有绿色打结的果蒂和几片浅绿叶子，底部有 Q 版黑色小短手、小短腿，大大的深棕色圆眼睛、小腮红、小嘴巴，表情生动可爱。3D 盲盒玩偶质感，漫射哑光材质，柔和一致光照，配色为粉色 #FFB6C1 系 + 桃子红 + 浅绿叶子点缀。

### 3.2 固定镜头 + 绿幕后缀（每条结尾粘贴）

> 固定镜头、固定机位，正面略俯视角度，机位全程不移动、不缩放、不旋转；角色始终居中，全身完整入画，头顶、手、脚不裁切。纯色纯绿背景，chroma key 绿幕背景，画面中只有角色一个主体，无其他物体，无文字，无水印，无阴影，无地面，无多余道具（动作需要的除外）。

> 说明：管线用 rembg（AI 抠图）去背，绿幕只是让它更容易分离，**不会把绿叶抠掉**，happy/rest 已验证通过。
> 时长选 5~8 秒即可；循环类动作选中间 2~3 秒稳定段做循环段。

## 4. 逐动作提示词（可直接复制 = 角色模板 + 动作句 + 后缀）

### 4.1 bored（无聊求关注）→ `bored.mp4`

> （角色模板）桃屁屁无聊地坐在地上托着腮发呆，眼神放空，慢悠悠叹一口气，然后发现镜头在看它，立刻坐直，眼睛发亮，小短手朝镜头挥了挥，期待地歪头，像在求关注。（后缀）

### 4.2 pet（摸头享受）→ `pet.mp4`

> （角色模板）桃屁屁被温柔地摸头，舒服地眯起眼睛，嘴角上扬，脸颊泛红，身体随着抚摸节奏轻轻左右摇晃，头顶冒出小爱心，一脸享受陶醉，动作轻柔治愈。（后缀）

### 4.3 shy（害羞）→ `shy.mp4`

> （角色模板）桃屁屁害羞地侧过身子，用小短手捂住脸，从指缝里偷偷看镜头，脸红扑扑的，身体扭捏地轻轻摇晃，然后忍不住笑出来。（后缀）

### 4.4 dance（跳舞庆祝）→ `dance.mp4`

> （角色模板）桃屁屁跳一段可爱的魔性舞蹈，扭动圆滚滚的屁股，摇摆小短手，左右踏步转一圈，节奏欢快，表情陶醉，周围飘起彩色纸屑和小星星。（后缀）

### 4.5 deflated-loop（瘪掉呼吸，可选）→ `deflated.mp4`

> （角色模板）瘪掉漏气的桃屁屁皱巴巴地瘫在地上，像泄气的气球，小短手无力垂着，眼睛半闭无神，身体随着微弱的呼吸轻轻起伏抽动，蔫蔫的很可怜。（后缀）

## 5. 拿到视频后的接入流程

1. 原视频放 `assets/video/source/`，用短英文名命名（如 `bored.mp4`）。
2. 跑管线（rembg 去背 → 480×500 透明画布 → 底部锚点 → VP9 Alpha WebM）：

   ```bash
   .venv-video/bin/python scripts/build-transparent-videos.py \
     assets/video/source assets/video/generated --only bored --only pet
   ```

3. `assets/video/manifest.json` 加 clip 条目（含循环时间段）。
4. `src/renderer/src/components/pet-motion-timeline.ts` 加 ClipTimeline。
5. `src/renderer/src/components/PetMotion.tsx` import 并注册到 clips 表。
6. 校验：`npm run videos:check` + `npm test`。

详细管线说明见 `docs/video-asset-workflow.md`；happy/rest 的完整接入案例见 `docs/assets/motion-prompts-new.md`。
